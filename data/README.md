# Data

The raw data are not included in this repository. Put the following files in this folder.

**SEER** (4,024 female patients diagnosed 2006-2010, November 2017 SEER update)
- `SEER Breast Cancer Dataset .csv` (semicolon-separated; note the space before `.csv`)
- Source: Teng, J. (2019). SEER Breast Cancer Data. IEEE DataPort. https://doi.org/10.21227/a9qy-ph35

**METABRIC**
- `data_clinical_patient.xlsx`
- `data_clinical_sample.txt`
- Source: METABRIC clinical data (Curtis et al. 2012, Nature 486:346-352; Pereira et al. 2016, Nat Commun 7:11479).
